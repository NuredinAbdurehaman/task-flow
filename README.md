\# Task Flow



Manage work. Keep it flowing.



\---



\## 🚧 Project Overview



Task Flow is a full-stack project management application inspired by tools like Jira and Trello.  



It allows users to:

\- Create projects

\- Manage tasks

\- Track progress using a Kanban-style board



This project is built for learning full-stack development and as a portfolio project.



\---



\## 🧠 Features (Planned)



\### MVP

\- User authentication (register/login)

\- Create projects

\- Create tasks

\- Basic task statuses (To Do / In Progress / Done)



\### Phase 2

\- Drag and drop tasks

\- Task comments

\- Assign users



\### Phase 3

\- Filters and search

\- Workflow rules

\- Notifications
