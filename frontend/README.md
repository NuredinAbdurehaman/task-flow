# Task Flow - Frontend

Frontend application for Task Flow project management system.

---

## 🚀 Tech Stack

- React (Vite)
- Tailwind CSS
- Axios
- React Router
- Shadcn ui
---

## ⚙️ Setup Instructions

### 1. Install dependencies
npm install

---

### 2. Start development server
npm run dev

Frontend runs at:
http://localhost:5173

---

## 🧠 Features (MVP)

- Login / Register pages
- Project dashboard
- Task board (Kanban layout)
- Task creation form
